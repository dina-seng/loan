# ប្រព័ន្ធគ្រប់គ្រងការខ្ចីប្រាក់ — Lending Management System

A mobile-first web app for tracking personal loans and repayments,
built with React + Vite + Tailwind CSS, backed by Google Sheets via Google Apps Script.

**Currency:** Khmer Riel (៛) · **Language:** Khmer + English

## Quick Start

1. Set up the Google Sheet + Apps Script backend — see [DOCUMENT.md](./DOCUMENT.md)
2. Copy `.env.example` to `.env` and set `VITE_APPS_SCRIPT_URL`
3. `npm install`
4. `npm run dev`

## Commands

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm test` | Run unit tests |

## Documentation

📖 **Full setup guide:** [DOCUMENT.md](./DOCUMENT.md) — written step-by-step for non-technical users.

## Tech Stack

- **Frontend:** React 19, Vite, Tailwind CSS
- **Backend:** Google Apps Script (no server needed)
- **Database:** Google Sheets
- **Font:** Noto Sans Khmer
